# 편집 레시피 — 5번 (👶 육아·자녀 고충) 「아들이 사회생활 배우고 곤란해진 이유」

원본: https://www.youtube.com/watch?v=83kfn7B1ocE

## 제작 리스트
- 타이틀 카드 디자인: 상단 고정 바 + 화이트 스모크 와이프 소스
- 캐릭터 시트: 3살 남아(셔츠+넥타이), 1살 여아(빨간 원피스), 어린이집 선생님(초록 앞치마), 엄마(리본 머리띠)
- 어린이집 배경 일러스트(사물함 복도)
- 집 거실 배경 일러스트(책장+식물)
- 부엌 배경 일러스트(반전 장면용)
- 규칙 텍스트카드 템플릿(초록 칠판)
- RPG 게임 UI 패러디 소스(잡체인지 문구 템플릿)
- 반전용 리액션 컷은 자체 제작 표정컷으로 대체 준비
- 이름표·출생연도 스티커 그래픽 소스
- 소용돌이눈·땀방울 등 감정 이모지 오버레이 세트

## 편집 순서
1. 훅: 타이틀 카드 1.87초 유지 후 0.2초 화이트 와이프 2컷 연속
2. 배경 리빌 후 캐릭터 등장, 이름표 스티커 삽입
3. 규칙 설명 구간은 2초 이상으로 느리게 유지해 가독성 확보
4. 유머 완화 비트(게임 드립)로 텐션 낮추기
5. '문제가...' 클리프행어 자막 삽입 후 반전 대상(여동생) 소개
6. 반전 장면은 배경을 붉은 화염톤으로 채도 급상승, 반응 강조 합성 적용
7. 동일 얼굴 클로즈업에서 자막만 2연속 교체(점프컷)로 반복 개그
8. 엔딩에서 인물 슬라이드인으로 여러 캐릭터를 한 프레임에 모아 코멘트+교훈 배치

## 컷 리듬 기준
- 평균 1.52초 · 분당 39.5컷 · 빠른 구간: 컷#2→#3 (0.2초씩 연속 2컷, 훅 도입부 화이트 와이프)
- 배속: 훅(0.2초 초고속) → 규칙 설명(1.6~2.7초로 감속) → 중반 유머 비트(1.1~2.0초 유지) → 반전·클라이맥스(1.17~1.24초로 살짝 재가속, 컷#16,17,19) → 엔딩 코멘트·루프(1.67~1.87초로 다시 감속)

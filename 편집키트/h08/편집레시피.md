# 편집 레시피 — 8번 (👶 육아·자녀 고충) 「아들이 대부분 갖고있다는 뛰어난 능력」

원본: https://www.youtube.com/watch?v=uukyy_oOt7c

## 제작 리스트
- 타이틀 카드용 화이트 플래시 1프레임
- 게시물 미리보기 카드 소재(화이트 글로우 테두리, 문구+아이콘+날짜, 정지 유지용)
- 스모크 와이프 전환 소재
- 딸 단독 등장 컷 + 남매가 함께 있는 상반신 컷(한 컷 안에서 순차 등장)
- 능력 언급용 캐릭터 클로즈업 2컷(대사 전/후)
- 스탯창 UI 그래픽(아이콘+텍스트 박스)
- 퀘스트 목록 UI 그래픽
- 점프·삼킴 사례를 표현할 전신 액션 일러스트 2장
- 비명 리액션 클로즈업(눈 질끈 감은 표정)
- 펀치라인 2단 자막용 배경 프레임(상단 일본어+하단 한국어 배치 고려)
- 엔딩 위험지도 풀샷(가구+라벨, 캐릭터는 작게 그리되 실루엣 아닌 풀컬러로)

## 편집 순서
1. 0.0~0.07s 화이트 플래시 1프레임 삽입
2. 0.07~2.17s 게시물 미리보기 카드를 화이트 글로우로 정지 노출(캐릭터 미등장)
3. 2.17~2.37s 스모크 와이프로 다음 장면 전환
4. 2.37~4.40s 딸 단독 등장 후 아들 합류로 남매 소개, 이어 4.40~7.91s 클로즈업 2컷으로 능력 언급
5. 7.91~9.84s 스탯창 UI를 하드컷으로 삽입해 반전 공개
6. 9.84~13.01s 퀘스트 목록 UI + 점프 사례 하드컷 연결
7. 13.01~15.32s 삼킴 사례 클로즈업 후 비명 리액션으로 급전환
8. 15.32~22.26s 펀치라인 2단 자막 → 해소 대사 → 엔딩 위험지도 풀샷 순으로 마무리

## 컷 리듬 기준
- 평균 1.59초 · 분당 37.7컷 · 빠른 구간: 가장 짧은 개별 컷은 샷1(0.067초, 화이트 플래시)과 샷3(0.20초, 스모크 와이프) — 둘 다 순간적인 전환 컷이며, 그 사이의 샷2(2.10초)는 오히려 카드가 길게 정지되는 구간이라 셋을 하나의 '빠른 연속컷'으로 보기는 어렵다. 실제 내용이 있는 컷 중에서는 샷11(0.834초)의 비명 리액션이 가장 짧다.
- 배속: 도입(0~2.4s) 급컷 → 설정(2.4~7.9s) 2초대 중속 컷 → 반전(7.9~9.8s) 다시 빨라짐 → 사례 나열(9.8~15.3s) 1.2~2초대 중속 → 펀치라인(15.3~17.9s) 2.6초로 늘어짐 → 엔딩(17.9~22.3s) 2초대로 마무리, 총 3번의 완급 전환이 있다.

## 소리
